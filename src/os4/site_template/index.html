OS4 results explorer

EM.411 OS4, H2 Team 13: autonomous road vehicles and e-bikes for Kendall Square. Every number here is generated by the Python model (python -m os4); nothing is typed in by hand.

Tasks

How to use it

  • Click ☆ next to any architecture (on any page) to select it. The selection is kept in this browser (localStorage) and listed on the Selected page, where you can export it as CSV.
  • Task 3 shows every road-only and bike-only architecture and every Pareto-front point; mixed fleets are a stratified sample (the page says how many of how many).
  • The site is static: open outputs/site/index.html straight from disk after uv run python -m os4, or download the CI artifact.
